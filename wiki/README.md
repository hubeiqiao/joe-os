# Public Wiki Layer

This folder is the public-safe LLM-maintained wiki layer for Joe's public repo.

The `sources/` folder remains the public raw-source layer. The wiki is the compiled synthesis layer for durable orientation and future questions.

Current layout:

- `index.md`: global page catalog
- `log.md`: append-only change log
- `entities/`: durable public entity pages
- `topics/`: recurring thematic synthesis
- `timelines/`: chronological synthesis
- `sources/`: public source maps
